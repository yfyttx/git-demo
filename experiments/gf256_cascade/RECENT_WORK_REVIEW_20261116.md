# GF(256) 级联码译码改进：近期工作总结

整理日期：2026-11-16。依据本地实验 CSV、日志与 `GUIDED_DECODING_RESEARCH.md`。本文是研究进展整理，未新增仿真；不同样本、矩阵和噪声点的 FER 不直接相减作为算法增益。

## 1. 目前取得了什么进展

已经显著改善原始译码器，但没有彻底解决 Z 侧失败。

最可靠的改善来自固定的 Turbo 消息交换参数调整：在两个外层矩阵种子上，原始 `conditioned_robust` 的逻辑 FER 约为 14%–15%，调整后的 `conditioned_robust_tuned` 约为 5%。随后加入 syndrome-flip 后处理，在第一矩阵的独立 1000 帧中进一步从 4.1% 降至 3.5%，CPU 时间增加约 25%。

其他尝试大多未得到可重复的增益。尤其是“让综合征通过”与“恢复正确逻辑态”之间仍有明显差距。近期还修复了多行 H2 下的逻辑等价评估错误，该修复提高了结果可信度，不能算作译码算法增益。

## 2. 研究对象和评价口径

当前主要实验使用 GF(256)、内长 12 的 path 级联结构：

\[
H_X^{\mathrm{cas}}=H_Z^{\mathrm{TIT}}\otimes G_2,\qquad
H_Z^{\mathrm{cas}}=\begin{bmatrix}
H_X^{\mathrm{TIT}}\otimes S\\ I_{582}\otimes H_2
\end{bmatrix}.
\]

单校验内码有 H2 为 1×12、G2 为 11×12。S 对应所选信息坐标；改变 G2 的基时需要保持投影、综合征和恢复步骤的坐标一致。矩阵具体输入以各实验 config 和哈希为准。

- Z 侧：利用 HX 的综合征恢复 Z 错误，是当前主要瓶颈。
- X 侧：利用 HZ 的综合征恢复 X 错误；通过 Pauli 信道相关性向 Z 侧提供条件先验。
- 常用比较点：退极化概率 p_D=0.07125，对应分量边缘翻转概率 f_m=2p_D/3=0.0475；部分诊断使用 p_D=0.072 或 0.04。
- 主要指标：稳定子等价意义下的量子逻辑 FER；另外记录 Z 综合征失败、漏检逻辑失败和 CPU 秒/帧。

Z 恢复残差满足 HX 综合征为零，只能说明校验通过；还要判断残差是否属于 HZ 的稳定子行空间。否则仍可能发生逻辑错误。

## 3. 各类改进尝试及结果

### 3.1 调整内外层 Turbo 消息交换：目前最明确的改善

调整消息混合/阻尼参数，形成 fixed tuned 基线；另实现 adaptive 版本按状态调整。这里的混合系数控制内外层概率消息更新，不能直接称为其他论文中的记忆 BP 参数。

同一行内为同矩阵、同噪声帧的配对比较，均在 p_D=0.07125：

| 外层矩阵种子 | 帧数 | 原始 robust | fixed tuned | adaptive |
|---|---:|---:|---:|---:|
| 20261018 | 300 | 41/300（13.67%） | 16/300（5.33%） | 15/300（5.00%） |
| 20261019 | 300 | 46/300（15.33%） | 15/300（5.00%） | 17/300（5.67%） |

第一矩阵 raw→tuned 救回 26 帧、退步 1 帧；第二矩阵救回 32 帧、退步 1 帧。对应配对检验 p 值分别约 4.17e-7、7.92e-9。tuned 在这两组中 CPU 也略低于 raw。

**结论：** 对当前信道点，固定消息交换设置的改善已有跨矩阵重复证据。adaptive 没有稳定超过 tuned，且更慢。另一个独立 100 帧实验二者均为 6/100，失败集完全相同。

**可能原因：** 较平缓的消息更新缓解了内外层循环反馈的振荡或过度确信。这是与结果一致的机制解释，尚未用独立机制消融证明所有增益都来自这一原因。

证据：[矩阵一三方法比较](results/paired_three_way_matrix20261018_300/summary.csv)、[矩阵二比较](results/paired_adaptive_vs_tuned_matrix20261019_300/summary.csv)、[独立100帧复验](results/path_tuned_vs_adaptive_holdout100_pD0p07125_seed20350000/summary.csv)。

### 3.2 G2 从 star 改为 path：短环减少，但 FER 未证明更好

12 列、300 帧、p_D=0.07125、原始 conditioned_robust 下：

| G2 表示 | HX 符号图四环数 | 逻辑失败 | Z 综合征失败 |
|---|---:|---:|---:|
| star | 166452 | 39/300（13%） | 38 |
| path | 35502 | 45/300（15%） | 43 |

path 救回 star 的 34 个失败帧，但也使 star 成功的 40 帧失败，配对检验 p≈0.561。四环减少约 79%，并没有转化成已证实的 FER 改善。后续采用 path 是为了利用链结构开展消息传递研究，不能表述为这次比较已经证明 path 更优。

**可能原因：** 同一码的生成矩阵换基会改变 BP 图、先验相关性和迭代轨迹；短环数量不是决定 FER 的唯一因素。6 列与 12 列还会改变码长等参数，本组结果不能证明单纯增加内长有效。

证据：[star/path 300帧](results/g2_basis_path_n12_300frames/aggregate_summary.csv)。

### 3.3 增强软信息、迭代调度和重启：多数无净收益

| 尝试 | 样本及比较 | 观察结果 |
|---|---|---|
| 完整 HZ BP 输出软 X 后验，再转 Z 先验 | 100帧，tuned 4→soft-X 4 次失败 | 失败集相同，CPU 约增加7.6% |
| 结构化 X 侧软消息，把外层和 H2 反馈结合 | 100帧，5→5 | 无配对救回，CPU 约增加8.8% |
| 外层 layered BP 更新顺序 | 100帧，7→6 | 仅救回1帧，另有漏检逻辑失败；证据不足 |
| 随机重复部分外层校验，增强其消息权重 | 20帧，1→1 | 同一失败帧，CPU 约增加13.5% |
| tuned 后增加 global restart-belief | 20帧，1→1 | 无救回，CPU 约增加40% |
| 延长迭代，回放预选的6个困难帧 | 6→6 | 两帧综合征通过但仍逻辑失败；不能作为总体FER样本 |

**可能原因：** X 侧原本已较可靠，更准确的 X 边缘未必解决 Z 外层投影的主要歧义；重新排序或增加迭代也可能停留在相同错误吸引域。上述负结果只针对当前实现和参数，不代表这些方法类别普遍无效。

证据：`results/softx_paired_dev100_matrix20261018_pD0p07125/`、`structured_softx_paired_dev100_matrix20261018_pD0p07125/`、`layered_outer_bp_paired_fresh100_matrix20261018_pD0p07125/`、`augmented_check_paired_pilot20_matrix20261018_pD0p07125/`、`paired_tuned_restart_global_pilot20_seed20320000/`、`path_failed6_long_vs_syndrome_flip_diagnostic/`。

### 3.4 投影修复、局部搜索和 OSD：暴露了逻辑类选择问题

| 尝试 | 比较结果 | 实际含义 |
|---|---|---|
| 可靠度引导的物理比特猜测 | 开发40帧4→3；独立100帧6→6 | 开发集改善未复现，独立样本CPU约增加27% |
| SI：暂时失活局部稳定子支持，再求解恢复 | p_D=0.072，100帧13→13 | 修复部分投影，但没有修复整帧逻辑失败 |
| joint projection | p_D=0.072，100帧10→26 | 救回1帧、退步17帧，逻辑结果明显恶化 |
| safe joint projection | 同组100帧10→10 | 10次综合征失败转成10次漏检逻辑失败，真实成功率没有改善 |
| OSD-2 联合列表 | 开发20帧3→6；另一20帧4→4（对照不同） | 未取得可靠增益，不能横向拼接不同对照 |

**已经观察到的机制：** 各外层投影共享物理符号；逐投影满足校验不代表它们与同一个物理误差估计相容。强制恢复一个综合征可行解，还可能选择错误逻辑陪集。

在一个 PEG 困难帧的离线审计中，扩大 OSD 列表后，投影2–8的真实投影仍未进入列表。这说明该帧的候选生成存在覆盖不足；只改变现有候选排序无法找回缺失候选。但“未覆盖真实投影”不自动等于“未覆盖所有稳定子等价成功解”，后者仍需逻辑类覆盖审计。

证据：`results/guided_guess_paired_holdout100/`、`si_paired_dev100_matrix20261018_pD0p072/`、`joint_projection_paired_dev100_matrix20261018_pD0p072/`、`joint_projection_safe_same_frames100_matrix20261018_pD0p072/`、`joint_list_osd2_dev20/`、`joint_list_osd2_holdout20/`。详细机制见 [研究日志](GUIDED_DECODING_RESEARCH.md)。

### 3.5 syndrome-flip：在 tuned 基线上获得小幅改善

只在 Z 综合征失败时，根据译码器后验选取低可靠度物理位，构造少量扰动 t，以移位综合征 s+HX·t 重译，再把 t 加回候选；按信道信息选择并核验原综合征。在线候选生成不读取真实错误。

第一矩阵，固定8个低可靠度位、重量1扰动，p_D=0.07125，新独立1000帧：

| 指标 | tuned | tuned + syndrome-flip |
|---|---:|---:|
| 逻辑失败 | 41/1000 | 35/1000 |
| FER | 4.10% | 3.50% |
| Z综合征失败 | 38 | 32 |
| 漏检逻辑失败 | 3 | 3 |
| CPU秒/帧 | 13.37 | 16.73 |

救回6帧、退步0帧，精确McNemar双侧p=0.03125；FER绝对降低0.6个百分点，相对降低约14.6%。这是固定矩阵和信道点上的正向证据；研究中尝试了多种方法，仍应结合独立复验解释，不能单凭一个p值宣称普遍增益。该分支不处理基线综合征已通过的错误，因此仍留下3次漏检逻辑失败。

**可能原因：** 扰动改变初始译码问题，使少数失败帧离开原来的错误固定点；代价是对困难帧多次重译。尚不能断言全部被救回帧具有同一种陷阱结构。

**第二矩阵已补完（2026-11-16）：** 原7对批次因单校验path内码误入系统形G2评估分支而报错。修复并核验实际矩阵后，保留未触发该分支的965帧，补齐35帧/方法。最终tuned为48/1000（4.8%），syndrome-flip为36/1000（3.6%）；Z综合征失败47→35，漏检逻辑失败均为1。救回12帧、退步0帧，McNemar双侧p=0.00048828125，CPU13.26→17.26秒/帧（约+30.2%）。这在第二矩阵上复现了增益，但仍只覆盖一个信道点。修复仅涉及终端逻辑评估，不作为算法增益；旧/新二进制及复用依据保存在completion_provenance.json。

证据：[第一矩阵1000帧汇总](results/path_tuned_vs_syndrome_flip_holdout1000_pD0p07125_seed20352000/summary.csv)、[配对检验](results/path_tuned_vs_syndrome_flip_holdout1000_pD0p07125_seed20352000/pairwise.csv)、第二矩阵目录 `results/matrix20261019_tuned_vs_syndrome_flip_holdout1000_pD0p07125_seed20353000/`。

### 3.6 PEG 多行 H2：当前候选效果较差，并发现评估器缺陷

构造H2=3×12、G2=9×12的系统形候选，增加通用G2因子消息译码。GF(8)无环小例24组条件与独立枚举吻合，最大后验误差约7.31e-13；说明这些局部计算通过核验，不保证真实多环图收敛。

同时发现原逻辑评估器只按单个尾部校验坐标处理，不能正确支持三行H2。已修复为消去全部三个校验坐标，并核验实际PEG矩阵的3492条HZ生成行：正交性、稳定子成员和陪集键均无异常。旧PEG实验中综合征通过的逻辑标签及用旧陪集键筛选的结果不能继续作为可靠结论。

修复后在p_D=0.04、相同20个物理噪声帧上：path为0/20，PEG为18/20，PEG失败全部是Z综合征失败。PEG加入syndrome-flip后仍18/20，CPU从12.77增至39.92秒/帧。

两码量子率分别11/36和1/4，不能作为只改变PEG算法的公平性能消融。H2本身girth=6，也没有阻止完整HX出现61110个四环（path为35502）。

**结论：** 该PEG候选及现有通用译码器组合不合适；尚不能把失败唯一归因于构造或译码器，也不能推断所有PEG内码都差。增加内层迭代使单帧未满足校验从1549降至约910后停滞，依然未成功。

证据：`results/path_same_frames_as_peg20_pD0p04_seed20330400/`、`peg3_syndrome_flip_corrected_eval_pilot20_pD0p04_seed20330400/`、`peg3_generic_inner_iters_single_frame_seed20272000/`；修复细节见研究日志。

## 4. 目前对失败原因的判断

1. **迭代参数确实影响性能。** 两个矩阵上raw→tuned的改善支持这一点；不能把过去高FER全部归因于矩阵有错。
2. **投影之间存在共享变量和相关性。** 当前结构下逐投影修复不能保证全局一致，已有修复局部但整帧仍失败的实例。
3. **短环是风险因素，但四环数不是充分解释。** star→path的大幅减环并未在300帧比较中降低FER。
4. **存在综合征可行但逻辑错误的候选。** safe joint projection的100帧实验明确展示了这一点；继续降低校验残差不一定降低逻辑FER。
5. **候选覆盖和先验质量可能同时限制性能。** 小规模精确消息检查已通过，但大图上的相关性近似、错误固定点和正确逻辑类覆盖仍未解决。
6. **评估实现曾有适用范围错误。** 多行H2评估器已修复，但不能由此声称整个项目所有域基和映射已被穷尽验证。

当前构造使用同一GF(256)上的普通Kronecker积。根据既有研究日志对Fan等论文的核对，它并非其内外码跨域构造的逐项复现；不能直接把该论文的距离保证和分阶段译码预期套到当前实现上。

## 5. 下一阶段应补齐的证据

- 第二矩阵缺失35帧/方法已补齐；保留评估器修复、旧/新程序哈希及完整配对汇总，后续使用修正后的评估器。
- 固定方法与预算，在预定邻近噪声点和第三矩阵验证；报告逻辑FER、配对救回/退步、平均CPU及困难帧尾延迟。
- 增加同计算预算的长迭代/重启及可行强后处理基线，判断收益来自候选机制还是额外计算量。
- 对独立失败帧审计逻辑类覆盖与选择错误；真值只用于离线分析，不参与在线候选选择。
- H2探索采用相同码率和明确坐标映射，连同最终HX图结构一起评估，避免仅根据内码girth选择。

组会可概括为：已经完成从原始译码到稳定基线的明显改进；后处理获得有限但真实的逻辑FER收益；同时通过负结果排除了若干简单修复路线，并明确了投影一致性和逻辑陪集判决这两个后续问题。当前仍不能声称Z侧问题已彻底解决或已达到论文发表标准。
