# 二进制内码与 GF(256) 伴随块乘法构造

H2 为 1×9 全一行，秩1；G2=[I8|1] 为8×9，是 H2 零空间的一组系统基。内码参数 [9,8,2]。

令 A=HZ_TIT、B=HX_TIT，M(a) 是多项式基 (1,alpha,...,alpha^7) 下乘 a 的列坐标矩阵。域多项式0x11d，alpha=2。

- HX 的 (i,j) 块为 M(A_ij) G2，普通二进制矩阵乘法。
- HZ 上半部的块为 M(B_ij)^T [I8|0]。
- HZ 下半部为 I582 ⊗ H2。
- 与论文行伴随矩阵约定对应：[a]=M(a)^T。

G2 [I8|0]^T=I8，G2 H2^T=0，配合 A B^T=0 保证 CSS 正交。

输出 NPZ 文件为 SciPy CSR 二进制矩阵。HX=1552×5238，HZ=2134×5238；物理码长5238、逻辑比特1552、码率8/27。manifest.json 记录实算秩和正交结果、输入哈希。

这不是原来 GF(256) 普通 Kronecker 的矩阵格式。旧仿真入口尚未适配；尚无本构造的 FER。下一步需要使用9个物理位到一个GF(256)符号的 G2 映射及相应先验进行译码。
