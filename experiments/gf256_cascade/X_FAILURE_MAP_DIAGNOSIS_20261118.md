# 新 9 位构造 X 侧失败与小型 GF(8) MAP 诊断

日期：2026-11-18。本文衔接 `X_FULL_HZ_FALLBACK_20261118.md`：完整二进制 BP 回退在独立 1000 帧中没有救回 68 个 X 综合征失败帧。本次工作检查失败帧的外层残差，并在可穷举小模型中量化 BP 与精确 MAP 的差距。

## 实际 GF(256) 构造：失败集中在外层符号估计

离线重放两组各 500 帧实验的原始随机流，只对原来 X 分阶段译码综合征失败的 68 帧重新计算外层输出。真实错误只用于事后比较；解码器仍只接收综合征、矩阵和信道先验。

| 诊断量（每帧，外层长度 582） | 中位数 | 四分位范围 | 范围 |
|---|---:|---:|---:|
| 与仿真真值不同的外层 GF(256) 符号数 | 112 | 94.25–124 | 55–199 |
| 未满足的外层校验行数（共 194 行） | 52 | 44.75–60 | 27–92 |

68/68 帧都存在外层符号估计错误，且 68/68 都有外层校验残差。这个结果把失败明确定位到外层 BP 没有收敛到满足给定上半部综合征的向量；尾符号由下半部恢复并不能修复这些上半部残差。它不说明矩阵映射错误，也不证明存在或不存在其他有效外层候选。

## 可穷举 GF(8) 小模型：精确 MAP 与同类二进制 BP

为验证“BP 搜索不足是否可能造成额外损失”，构造一个仅 8 个物理比特的级联类比模型：

\[
G_2=[I_3\mid \mathbf 1],\quad H_2=[1\;1\;1\;1],\quad
u_0+\alpha u_1=0,\quad \alpha=x\in\mathrm{GF}(8),
\]

其中 GF(8) 使用本原多项式 \(x^3+x+1\)。外层 GF(8) 校验展开为 3 个二进制校验，再叠加两个内层奇偶校验，得到 5×8 二进制校验矩阵。穷举全部 256 个物理错误向量，在 BSC \(p=0.0475\) 上按每个综合征的后验概率计算精确 MAP，并与完整矩阵二进制 sum-product BP（最多 100 轮）比较。

| 指标 | 精确 MAP | 二进制 BP |
|---|---:|---:|
| 物理块错误概率 | 2.96% | 5.22% |
| 未满足综合征的概率质量 | 0 | 5.01% |

在这个小模型里，MAP 与 BP 的差距表明：即使矩阵与信道模型正确，BP 也可能因循环和消息近似而错过有效/高概率候选；而 MAP 本身仍有非零错误，表示综合征下也存在不可消除的信道歧义。

**边界：**这个玩具例子是经典物理错误向量块错误率，没有量子稳定子陪集、没有 GF(256) 外层图、也没有 X→Z 条件先验。它只证明“算法损失与信道歧义可以同时存在”，不能把 2.96% 或 5.22% 外推为当前量子码 FER。

## 当前判断与后续

现有证据支持优先改进 X 侧外层候选搜索，而不是继续重复同一个完整图硬判决 BP 回退。下一步可在真实失败帧上比较 syndrome-valid 的外层列表候选覆盖率与小码 exact-MAP；在线候选排序不得使用真实错误。任何新译码分支应先在冻结开发集配对比较，再用独立噪声种子验证量子逻辑 FER。
